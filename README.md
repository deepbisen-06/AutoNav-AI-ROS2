# AutoNav AI — ROS 2 Autonomous Mobile Robot

A 60-day hands-on robotics learning project using ROS 2 Jazzy.

## Project Goal
Develop an autonomous mobile robot capable of mapping,
navigation, obstacle avoidance, and AI-based perception.

## Tech Stack
- Ubuntu 24.04
- ROS 2 Jazzy
- Python
- Gazebo
- RViz2
- Nav2
